# 🎯 회계/경제 상식 퀴즈 게임 (Accounting & Economics Quiz Game)

파이썬(Python) 기본 문법과 객체 지향 클래스(Class), 그리고 JSON 파일 입출력을 활용하여 만든 콘솔 기반의 인터랙티브 퀴즈 게임입니다.

---

## 💡 퀴즈 주제 선정 이유
* **전공 연계 및 실용성:** 회계학 전공자로서 대학 생활 동안 배운 회계 및 경제 기초 개념(재무상태표 회계등식, 손익계산서, 원가 회계, 부가가치세, 감사의견 등)을 복습하고, 어렵게 느껴질 수 있는 전공 지식을 누구나 쉽고 재미있게 퀴즈로 접할 수 있도록 기획했습니다.

---

## 🚀 실행 방법
터미널 창에 아래 명령어를 입력하여 게임을 실행할 수 있습니다.
```powershell
python main.py
🛠️ 기능 목록
퀴즈 풀기: 저장된 퀴즈를 순서대로 출제하고 정오답을 채점한 뒤, 100점 만점 환산 점수와 최고 점수(Best Score)를 갱신합니다.

퀴즈 추가: 사용자로부터 문제, 4개의 선택지, 정답 번호(1~4)를 입력받아 새로운 퀴즈를 등록하고 즉시 파일에 저장합니다.

퀴즈 목록: 현재 등록된 모든 퀴즈의 목록과 문제 번호를 조회합니다.

점수 확인: 게임 플레이 중 갱신된 역대 최고 점수를 언제든 확인할 수 있습니다.

안전한 종료: 프로그램 종료 시 데이터를 안전하게 저장하며, 강제 종료(Ctrl+C 등) 시에도 예외 처리를 통해 데이터 유실을 방지합니다.

📁 파일 구조
